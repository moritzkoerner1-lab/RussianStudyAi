# ВЖИВУЮ

Russian as people actually say it — two weeks before Moscow.

## Modes

- **Speak** — Ara or Lev, native tutors that correct live (EN or DE help)
- **Walk** — camera + voice tutor for the real world
- **Drill** — high-utility Moscow chunks inside sentences (build + recall)
- **Notebook** — one beautiful pile with auto typology
- **Path** — 14-day mission with read / recall / again

## Run

```bash
npm install
npm run dev
```

Bind `OPENAI_API_KEY` for live tutoring and vision. Without it, a rich demo tutor still works offline.
